## 任务：下载 qwen2.5:7b-instruct 模型并导入 Ollama

### 背景
用户终端 `ollama pull qwen2.5:7b-instruct` 速度极慢（代理节点约 500 KB/s，预计 2.5 小时）

### 方案与执行
1. **测速对比**：Ollama 代理拉取 500 KB/s vs ModelScope 国内直连 ~3 MB/s（6 倍快）
2. **ModelScope 下载**：用多线程 Python 脚本下载 Q4_K_M 量化版本（2 个分片文件，共 ~4.36GB）
3. **GGUF 分片合并**：使用官方 `gguf` Python 包（GGUFReader + GGUFWriter）合并为单文件
   - 安装：`pip install gguf`（v0.19.0）
   - 关键点：不传 `raw_shape`（让 writer 从 byte shape + raw_dtype 自动推导），跳过 `split.*` 字段，正确提取数组类型字段
4. **Ollama 导入**：`ollama create qwen2.5:7b-instruct -f Modelfile` 成功
5. **验证**：`ollama run qwen2.5:7b-instruct "你好"` 正常回复

### 踩坑记录
- Ollama 无法直接导入分片 GGUF（报 "has 1 shards, expected 2"），因为它把第一个分片复制到 blob 目录后找不到第二个
- `gguf` 包的 `GGUFReader.fields` 结构：`field.data` 是指向 `field.parts` 的索引列表，最后一个索引指向值
- `GGUFWriter.add_tensor` 的 `raw_shape` 参数期望 byte shape，不是逻辑 shape；不传则用 `tensor.shape`（byte shape）自动推导
- 沙箱环境禁止删除文件，下载脚本的清理逻辑需要 try-except
